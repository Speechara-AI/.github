# 🎙️ Speechara.AI

<p align="right"><a href="https://github.com/Speechara-AI/.github/blob/main/profile/README.md">Русская версия</a></p>

**Speechara.AI** is an AI assistant for live listening: real-time transcription, translation, and structured meeting notes.

We help teams turn conversations into clear next steps:
- real-time transcription and translation
- concise summaries and action items
- automatic meeting protocols
- suggested answers during the conversation
- one experience across web, macOS, and Windows
