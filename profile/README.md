# 🎙️ Speechara.AI

AI-powered live listening assistant for people who build, support, and lead meetings in real time.

We help teams capture ideas and decisions with less friction:
- real-time transcription and translation
- concise summaries and action items
- protocol generation
- suggested responses during calls
- support for multiple clients and workflows
